# fantasy-football-assistant

An independent, non-commercial personal fantasy football analysis tool that uses the Yahoo Fantasy Sports API.

This application is intended solely for my own use. It is not offered to the public, sold, monetized, or used by a business.

## Purpose

The purpose of this project is to help me analyze and manage decisions related to my own Yahoo Fantasy Football team.

The application will use read-only Yahoo Fantasy Sports data to support analysis such as:

* Weekly lineup decisions
* Waiver-wire analysis
* Identifying players available in my league
* Comparing available players with my current roster
* Roster construction and positional needs
* Weekly matchup analysis
* League standings
* Recent league transactions
* Reviewing other team rosters to determine player availability

## Yahoo Fantasy Sports Data

The application may retrieve the following information through the Yahoo Fantasy Sports API:

* My fantasy leagues
* League settings and scoring rules
* My fantasy team
* My current roster
* Player information
* Player ownership and availability within my league
* Weekly matchups
* League standings
* League transactions
* Other team rosters where available through the Yahoo Fantasy Sports API

This information will be used only to analyze my own fantasy football league and team.

## Intended Users

The application has one intended user: me, the developer.

This is a personal project and is not intended to become a public-facing fantasy sports application.

There are no external customers or users.

The application will not:

* Offer accounts to other users
* Provide Yahoo Fantasy data to third parties
* Sell access to Yahoo Fantasy data
* Monetize Yahoo Fantasy data
* Be used by a company or other business

## API Access

The application requires read-only access to the Yahoo Fantasy Sports API.

Authentication will use Yahoo's supported OAuth process to access my own Yahoo Fantasy account.

The application will not use the API to perform transactions or make changes to my Yahoo Fantasy account.

It will not submit:

* Lineup changes
* Waiver claims
* Player adds or drops
* Trades
* League setting changes

Any roster or lineup recommendations generated by the analysis tool will be informational. I will make any resulting changes directly within Yahoo Fantasy.

## Data Use

Yahoo Fantasy Sports data retrieved through the API will be used solely for personal fantasy football analysis.

Yahoo data will not be:

* Sold
* Licensed
* Redistributed
* Used for advertising
* Used for commercial purposes
* Made available through a public database
* Provided to unrelated third parties

The application is not intended to scrape Yahoo webpages. Yahoo Fantasy information will be obtained through the authorized Yahoo Fantasy Sports API.

API credentials, OAuth tokens, and other authentication secrets will remain private and will not be published in this repository.
