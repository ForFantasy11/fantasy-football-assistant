Personal Fantasy Football Assistant

A non-commercial personal application using the Yahoo Fantasy Sports API to support analysis of my Yahoo Fantasy Football team.

Personal Use Single User Read Only

Purpose

The application helps analyze weekly fantasy football decisions including lineups, waiver options, roster construction, matchups, standings, and league transactions.

Yahoo Fantasy Sports Data

The application may retrieve:

  • League information and settings
  • Team and roster information
  • Player information and league availability
  • Weekly matchups
  • League standings
  • League transactions
  • Other league rosters where available through the API

Users

This application is intended for one user: the developer. It is not a publicly available fantasy sports service.

API Access

The application uses Yahoo OAuth 2.0 and requires read-only access. It does not make lineup changes, waiver claims, trades, adds, drops, or other changes to Yahoo Fantasy accounts.

Data Use

Yahoo Fantasy Sports data is used only for personal fantasy football analysis. Data will not be sold, redistributed, used for advertising, or provided to third parties.
